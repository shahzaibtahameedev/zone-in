### Code Style

- Always wrap result of methods in a well named const variable and return the variable.
- Always have a line space before return.
- Avoid spread operatiors.
- Avoid nested ternary operators. Use if/else or switch instead.
- Avoid unnecessary comments. Code should be self-explanatory through meaningful naming.
- Use switch statements when handling more than two distinct conditions.
- Avoid unnecessary abstractions. Don't create helper methods for one-line operations unless they improve readability.
- Prefer const over let. Only use let when reassignment is required.
- Avoid magic numbers and hardcoded strings. Extract frequently used or meaningful values into named constants.
- Avoid non-null assertions (!). Handle nullable values explicitly.
- Use async/await instead of unnecessarily chaining .then() and .catch().
- Use camelCase for variables and functions.
- Use PascalCase for classes, interfaces, types, and enums.
- Use UPPER_SNAKE_CASE for global constants where appropriate.
- Use descriptive file names in kebab-case.
